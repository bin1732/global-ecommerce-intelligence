# PPC 广告管理指南

> 电商付费广告(PPC)架构、指标、策略
> 覆盖 Amazon PPC / Shopee Ads / 淘宝直通车 / TikTok Shop Ads
> 最后更新：2026-08-23
> 最后核实：2026-08-23
> 核实周期：每半年（广告规则变动较慢，半年复核）

## 一、核心广告指标

| 指标 | 全称 | 公式 | 健康值 |
|------|------|------|:------:|
| CPC | Cost Per Click | 花费/点击数 | 因品类而异 |
| CTR | Click-Through Rate | 点击数/曝光数 | >0.3%(Amazon) |
| CVR | Conversion Rate | 订单数/点击数 | >10%(Amazon) |
| ACOS | Advertising Cost of Sales | 广告花费/广告销售额 | <30%(成熟期) |
| TACOS | Total ACOS | 广告花费/总销售额 | <15%(健康) |
| ROAS | Return on Ad Spend | 广告销售额/广告花费 | >4(健康) |

### ACOS vs TACOS 的关系

```
TACOS = ACOS × (广告销售额 / 总销售额)
```

- **ACOS 高 TACOS 低** → 广告亏但自然单补上,可接受(冷启动期)
- **ACOS 低 TACOS 高** → 广告赚钱但自然单差,Listing有问题
- **双高** → 危险,广告亏+自然差,需停投诊断
- **双低** → 健康,广告自然双良性

## 二、Amazon PPC 广告架构

### 三种广告类型

| 类型 | 展示位 | 适合 | 出价方式 |
|------|--------|------|---------|
| Sponsored Products(SP) | 搜索结果+商品页 | 所有卖家必投 | CPC |
| Sponsored Brands(SB) | 搜索结果顶部 | 品牌注册卖家 | CPC |
| Sponsored Display(SD) | 商品页/站外 | 重定向+受众 | CPC/CPM |

### SP 广告三种匹配

| 匹配类型 | 精准度 | 流量 | 建议 |
|---------|:------:|:----:|------|
| Broad 广泛 | 低 | 大 | 挖词期 |
| Phrase 词组 | 中 | 中 | 优化期 |
| Exact 精准 | 高 | 小 | 主投(转化最好) |

**否定关键词**：广泛/词组匹配必加否定词,排除无关流量。

### 广告架构(标准三段式)

```
┌─ 自动广告(发现词)
│   └─ 4个匹配类型各开一个广告组
│
├─ 手动-精准(主投)
│   └─ 高转化词 exact 匹配,出价最高
│
└─ 手动-广泛/词组(扩流)
    └─ 中等转化词 broad/phrase,加否定词
```

**词流转规则**：
- 自动广告跑出高转化词 → 提取到手动精准
- 手动广泛跑出好词 → 提取到手动精准
- 手动精准转化差的词 → 否定或降价

## 三、出价与预算策略

### 出价策略(按阶段)

| 阶段 | 目标 | 出价 | ACOS预期 |
|------|------|------|:--------:|
| 冷启动(0-2周) | 跑数据 | 高于建议出价50% | >100%正常 |
| 优化期(2-8周) | 提转化 | 按转化调价 | 50-80% |
| 稳定期(2月+) | 控成本 | 精准词维持,差词否 | <30% |
| 爆款期 | 抢位 | 头部词加价抢首行 | 可接受高ACOS |

### 预算分配

- 新品：自动60% + 手动精准40%
- 成熟品：自动20% + 手动精准60% + 手动广泛20%
- 单广告组预算：建议≥$30/天(跑出有意义数据)
- 关键词出价：从建议出价起步,7天观察期再调

## 四、广告报表解读

### 4大核心报表

| 报表 | 频率 | 看什么 |
|------|:----:|--------|
| 搜索词报告 | 周 | 跑出什么词,哪些转化好/差 |
| 广告活动报告 | 周 | 整体ACOS/CVR趋势 |
| 广告位报告 | 月 | 搜索首行/商品页/其他位表现 |
| 投放报告 | 月 | 各关键词/ASIN表现 |

### 关键动作清单(每周)

```
1. 搜索词报告
   → 高转化词 → 提取到手动精准(提价)
   → 高点击低转化词 → 否定
   → 无关词 → 否定

2. 广告位报告
   → 搜索首行转化好 → 调位竞价 +20-50%
   → 商品页转化差 → 降位竞价

3. ACOS 监控
   → 单个词ACOS>100%且CVR<5% → 降价或否定
   → 单个词ACOS<15%且转化高 → 加价抢量
```

| 平台 | 广告名 | 出价 | 核心指标 | 特点 |
|------|--------|:----:|---------|------|

## 六、广告诊断速查

| 症状 | 可能原因 | 处理 |
|------|---------|------|
| 高曝光低点击 | 主图差/标题差/出价低 | 优化主图+提价 |
| 高点击低转化 | Listing差/价格高/评价少 | 优化Listing+降价+测评 |
| ACOS飙升 | 竞品抢词/转化下滑 | 查搜索词+查竞品 |
| 无曝光 | 出价太低/词太冷 | 提价+换词 |
| 广告花不出去 | 预算低/竞价低 | 加预算+提竞价 |
| TACOS高ACOS低 | 自然单差 | 优化Listing自然权重 |

## 七、广告预算占销售额比例建议

> 以下为行业经验值，因品类/阶段差异大 [置信度:中]

| 品类 | 冷启动期 | 成熟期 |
|------|:-------:|:------:|
| 电子配件 | 30-50% | 10-15% |
| 服装 | 25-40% | 8-12% |
| 家居 | 20-35% | 8-12% |
| 美妆 | 30-50% | 15-20% |
| 食品 | 15-25% | 5-8% |

广告占比超50%且持续2周以上 → 危险信号,需诊断Listing/价格/评价。
