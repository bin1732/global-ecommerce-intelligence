> 最后核实：2026-08-23
> 核实周期：每季度（平台规则频繁变动）

## 国内平台核心规则

| 平台 | 违规高发区 | 处罚等级 |
|------|----------|----------|
| 淘宝/天猫 | 虚假交易、售假、滥发信息 | 扣分→降权→封店 |
| 京东 | 价格违规、虚假宣传、物流超时 | 扣分→限制→清退 |
| 拼多多 | 延迟发货、质量抽检、活动违约 | 罚款→限制→关店 |
| 抖音电商 | 虚假宣传、违规引流、售后问题 | 扣分→限流→关闭橱窗 |
| 快手电商 | 商品不符、夸大宣传 | 扣信誉分→限制 |

## 跨境平台核心规则

| 平台 | 违规高发区 | 处罚等级 |
|------|----------|----------|
| Amazon | 侵权、操纵评价、关联账号 | 下架→限制→封号(永久) |
| Shopee | 迟发率、退货率、仿品 | 扣分→限制→冻结 |
| Lazada | 物流时效、产品合规 | 扣分→降权→封店 |

## 通用违禁词分类

| 类别 | 示例 |
|------|------|
| 绝对化用语 | 第一、最好、顶级、100% |
| 虚假宣传 | 根治、永不复发、无效退款（部分行业） |
| 违禁品 | 管制刀具、药品、烟草 |
| 广告法禁用 | 国家级、最佳、极品 |

## 各国电商合规要点

| 国家/区域 | 关键合规要求 |
|-----------|-------------|
| 中国 | 营业执照、ICP备案、广告法 |
| 美国 | FDA(食品/化妆品)、FCC(电子产品)、CPSC(儿童产品) |
| 欧盟 | CE认证、GDPR、WEEE、REACH |
| 日本 | PSE(电器)、JIS认证 |
| 韩国 | KC认证 |
| 东南亚 | 各国清真认证、化妆品注册 |
