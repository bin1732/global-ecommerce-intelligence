## 一、监控清单（每个 SKU 提前定义 N 个直接竞品）

直接竞品定义（同时满足 3 条中至少 2 条）：
1. 同主关键词搜索首页前 20 位
2. 价格在我方 ±30% 范围内
3. 评分 ≥ 3.8 且评价数 ≥ 50

每个我方 SKU → 至少选 5 个直接竞品、10 个间接竞品。推荐用 `scripts/competitor-checklist.mjs` 先过一遍 checklist。

```bash
node scripts/competitor-checklist.mjs --product B0XXXXXX --platform amazon --json --save
```

## 二、监控维度 & 频率

| 维度 | 频率 | 工具 / 方法 | 预警阈值 |
|------|------|------------|----------|
| 售价变动（含Coupon/Deal） | 每日 | 第三方工具或手动记录 | **单次变动 ≥ 8% 或 7 天累计 ≥ 15%** → 橙色预警 |
| 主图 / 标题 / 五点 / A+ 大改 | 每日 | 截图对比工具 / 肉眼 | 任何一项修改 ≥ 20% → 黄色预警 |
| BSR 排名变动 | 每日 | BSR 快照 | 7 天飙升 ≥ 30%（对手爆单）或 跌 ≥ 30%（对手出事）→ 黄色 |
| 评分 / 评价数 / 差评率 | 每周 2 次 | 平台页 + sentiment | 评分掉 ≥ 0.3 或 差评率 ≥ 15% → 对手机会点 |
| 广告卡位（核心词首页前 4） | 每周 | 搜词看 SP/SB 位置 | 我方掉出前 4 + 新对手进前 4 → ACOS 预警 |
| 上新品（同类目同价位） | 每周 | 新品榜 / BSR飙升榜 | 上 ≥ 3 个 SKU 且首周评价增长快 → 对手测款成功，需跟价/测款跟进 |
| 促销节奏（黑五/PrimeDay/大促） | 大促前 4 周+期间 每日 | 前台促销栏 | 竞争对手大额 Coupon / LD / 7DD → 我方提前应对 |

## 三、价格战应对 4 档策略（**不允许上来直接硬跟**）

### 档 1：对手降 ≤ 5%，持续 ≤ 7 天
→ **先不跟**。先观察 7 天：我方转化是否真的掉 ≥10%。很多对手是短期清仓，跟了就降下来再也涨不回去。

### 档 2：对手降 5-15%，持续 ≥ 7 天，且我方转化掉 ≥10%
→ **软性应对（先于硬降价）**，按顺序试：
1. 给 Coupon / 折扣码（不影响 Listing 前台价格锚点）
2. 加 买 2 件 / 捆绑销售 变相降价
3. PPC 加投 20%，稳住排名
4. 发 5 个 Vine / 测评（合规范围内）拉评分

### 档 3：对手降 ≥ 15%，持续 ≥ 14 天，且我方 BSR 掉 ≥ 20%
→ **此时才考虑硬降价**。但先过 SOP-03 调价流程 + 价格弹性计算。
如果调价幅度 ≥ 10% → **必须**专家团合议。

### 档 4：对手亏本甩卖（价格低于我方可变成本）
→ **绝对不跟**。恶性价格战的最后都是双输，对手撑不住自己会撤。转做差异化（加功能/改款/升级包装/加赠品/提评分）拉开距离。

## 四、周报 & 月报模板
### 周报每周一必出（一页纸）
1. 本周 TOP5 竞品价格热力图（我方 vs 5 竞品）
2. 本周重大变动：XX 降价 / YY 大改 Listing / ZZ 上新品
3. 我方关键指标 vs 上周：BSR / 转化 / 评分 / ACOS
4. 下周行动建议（≤3 条 P0）

### 月报：
1. 月度价格战复盘（我方调价 N 次，哪些成功哪些失败）
2. TOP10 竞品 6 维度雷达图对比
3. 新品机会 TOP3
4. 下季度风险 TOP3
