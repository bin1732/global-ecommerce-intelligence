## 一、新品首次定价 5 步法

### Step 1 — 利润打底（绝对底线）
先跑一次 profit_calculator：
```bash
python scripts/profit_calculator.py --price <候选价> --cost <采购> \
  --commission <平台佣金%> --logistics <物流> --marketing <广告%> --return-rate <退货%> --json
```
硬性底线：净利润率 ≥ 15%（否则广告 / 退货 / 促销一上就亏）

### Step 2 — 竞品锚定
对 10 个直接竞品统计：P10 / P25 / P50 / P75 / P90 五档价格
- 锚定策略：
  - 差异化卖点充足（功能/外观/品牌）→ 可在 P60-P75 档
  - 普通改款 → P40-P60 档
  - 纯铺货无差异化 → P20-P35 档（只靠量）

### Step 3 — 价格弹性测试（有历史数据时）
有 2 组以上「价格 - 销量」数据时调用：
```bash
node scripts/price-elasticity.mjs --p1 <旧> --q1 <旧销量> --p2 <新> --q2 <新销量> --json
```
解读：
- |E| > 1（高弹性）：降价有效 → 总收入会提；
- |E| < 1（低弹性）：提价有效 → 总收入会提；
- **诚实标注**：2 组数据只是点弹性，样本小 → 置信度【低】

### Step 4 — 价格阶梯 & 锚点设计
- 单 SKU 至少 3 档：引流款（微利 5-10%） / 利润款（20-30%） / 形象款（40%+，主要为衬托利润款）
- 多数量折扣：买 2 件 95 折，买 3 件 9 折（提高 AOV）

### Step 5 — 首次上线价 = 「利润底价 + 10% 预留促销空间」
原因：平台大促（黑五/双11/9.9）要打折，不能低于利润底价。

## 二、老品调价流程（触发调价的 5 种情况）

| 触发信号 | 调价方向 | 调价幅度参考 | 是否专家团合议 |
|----------|---------|--------------|----------------|
| TOP3 竞品连续 7 天降 ≥5%，我方转化掉 15%+ | 跟降 3-5% | 不低于利润底价 | <10% 单SKU→否；≥10%→是 |
| BSR 连续 2 周掉 ≥20%，但转化不掉 | 不一定（先看排名水分） | 先不动价，先加 PPC/优惠券 | |
| 库存 ≥90 天滞销 | 清仓降价 20-30% 或 站外 Deal | 不低于可变成本 | ≥10% → 是 |
| 原材料涨 ≥10%，毛利率跌破 15% | 提价 5-8% | 分批提，不要一下一步到位 | ≥10% 或批量→是 |
| 旺季（黑五/圣诞/618）前 4 周 | 提前规划促销价（预留 5-10% 促销空间）；大促价不得高于近 30 天最低成交价（合规红线：禁止先涨后降的虚假促销，违反平台价格保护与价格欺诈规定） | 配合促销节奏 | 批量→是 |

### 调价后的 14 天 AB 观察指标
调价后**绝对不能**直接不管，必须盯：
- 转化率 CR 变化（±≥10% 异常）
- 点击率 CTR 变化（±≥10%）
- BSR 排名变化
- ACOS（广告成本占销比）变化
- 7 天滚动毛利率

## 三、调价失败的回滚机制
- 调价后 7 天内 **总收入下降 ≥10% 且非季节性原因** → 立即回滚原价
- 回滚后 7 天再分析，不能反复横跳（价格锚点打乱得不偿失）
