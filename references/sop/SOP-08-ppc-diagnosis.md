## 一、诊断频率
- 日常（小预算）：每周 1 次，15 分钟
- 日常（中预算，≥¥5000/月）：每周 2 次，每次 30 分钟
- 月度复盘（所有预算档）：每月第一周，2-3 小时深诊
- **大预算触发**：当预算 ≥ 月毛利 **20%** → 触发 SKILL.md 专家团合议第 5 条

## 二、核心 6 指标（健康阈值）

| 指标 | 含义 | 健康阈值 | 警戒值 |
|------|------|---------|--------|
| **ACOS** | 广告花费 / 广告带来的销售额 | < 毛利率 × 70% | > 毛利率 |
| **TACOS** | 广告总花费 / **全店**总销售额 | ≤ 15% | > 25% |
| **CTR** | 点击率 | ≥ 0.35%（亚马逊）；≥ 1%（国内平台） | < 0.2% |
| **CVR** | 转化率 | ≥ 10% | < 5% |
| **CPC** | 每次点击成本 | 低于单次点击毛利（毛利 × CVR） | 超了就亏 |
| **RoAS** | 广告销售额 / 广告花费 | ≥ 3 | < 2 |

## 三、标准优化动作库（像调参表一样照抄）

### A. CTR 低（<0.2%）—— 主图 / 标题 / 价格问题
1. **先看主图**：7 天点击率 TOP3 位置的对手主图对比；我方是不是白底 1000px+、卖点明显、差异化卖点标清楚
2. **再看标题**：前 60 字符 = 强关键词 + 差异化一句话；没有废话堆砌
3. **价格 & Coupon**：定价 > TOP3 均价 10% + 没 Coupon → CTR 天然低（先调价格再调广告）
4. **评分**：< 4.0 先去修评分（SOP-06），别来浪费广告费

### B. CVR 低（<5%）—— Listing / 价格 / 评价问题
1. **Listing 质量分 <80** → 先回 SOP-10 优化到 ≥80
2. **差评置顶** → 点「Not helpful」+ 客服回复 + 近期上 10 条带图好评顶下去
3. **价格锚点**：前台价高 + 无 Coupon / 促销 → 先做软性降价
4. **QA 问题没覆盖**：TOP10 常见问题没回答 → 24h 内补齐

### C. ACOS 过高（> 毛利率）
按顺序来，不要一口气全调：
1. **关词**：7 天花费 ≥ ¥100 且 **0 单 + 0 Cart** 的关键词 → 直接精准否定
2. **降价**：7 天 ACOS 超毛利率 2x 的关键词 → 降 Bid 10-15%，观察 3 天
3. **否 ASIN**：自动广告跑出的"别人的 ASIN"有点击无转化 → 否定 ASIN
4. **加否定大词**：广泛匹配跑出的不相关大词（比如你卖"蓝牙音箱户外"跑出"蓝牙音箱专业舞台"）→ 词组否定
5. **提转化**：回到 B 项优化 Listing（降 ACOS 最根本方法还是 CVR 上去）

### D. 钱花不出去（预算跑不完 / 曝光少）
1. 看 Bid：太低 → 往上加 10-20%
2. 看词数太少：词量 < 30 个 → 加长尾词
3. 看匹配太窄：全部精准 → 拆出 30% 预算给广泛 / 词组
4. 看账户健康度：被审核过 → 恢复要 3-7 天，别硬加预算

## 四、账户结构（三段式漏斗，所有账号必须遵守）

所有广告按"认知 → 考虑 → 转化"分三层，预算按 3:4:3 分：
```
上层(30%预算) — 品牌 / 品类大词 + SB/SD 广泛：拉新曝光
中层(40%预算) — 长尾精准词 + 自动广告：抓精准流量打转化
下层(30%预算) — 再营销 / 再定位 / 品牌防御：捡回流失、防竞品截流
```
→ **不得**出现「一个广泛组包含所有词所有预算」这种孤注一掷式结构（亏到哪里都不知道）

## 五、月度复盘 6 问（必须答完）
1. 本月 ACOS / TACOS / RoAS vs 目标？差在哪？
2. TOP10 烧钱词的产出：哪些是功臣、哪些是吸血鬼？
3. Search Term Report：跑出了哪些新词值得加？哪些要否？
4. SB/SD 上层漏斗 vs 精准组的 CPA 对比？
5. 竞品广告位：哪些词我方从进首页 → 掉出去了？
6. 下月预算调整方向 + 幅度（≥20% 要专家团过）
