> 库存 = 钱。压多了 = 亏仓储费 + 贬值 + 现金流断；压少了 = 断货 → BSR 掉光 → 后面补回来花 3 倍广告费。

## 一、库存健康度 4 指标（每周扫一次，所有 SKU）

| 指标 | 公式 | 健康 | 警告 | 危险 |
|------|------|------|------|------|
| **可售天数 DOS** | 可售库存 ÷ 近 30 天日均销量 | 45 ~ 75 天 | 20~44 或 76~120 | <20 或 >120 |
| **在途 DOS** | 在途库存 ÷ 日均 | 25 ~ 45 天 | 10~24 | <10 → 断货预警 |
| **冗余库存率** | (>90 天 DOS 的库存价值) ÷ 总库存价值 | ≤ 15% | 15~30% | >30% → 立即清仓 |
| **库存周转率 ITR** | 近 90 天销售成本 ÷ 平均库存价值 | ≥ 2 次/季度 | 1~2 | <1 → 钱全压库存 |

## 二、补货公式（经典 补货点 = 安全库存 + Lead time 销量）

```
补货量 Q =  (LeadTimeDays + SafetyDays) × DailySales − (OnHand + InTransit − Reserved)

其中：
  LeadTimeDays = 头程海运 25~45 天 / 空运 5~10 天 / 快递 1~5 天（按实际）
  SafetyDays   = 近 3 个月销量波动天数 × 1.645（90% 服务率）；
                 平季 7~14 天；旺季 / 大促前 21~30 天
  DailySales   = 近 30 天加权移动平均（近 7 天权重×2）
  OnHand       = FBA / 海外仓 当前可售
  InTransit    = 已发还没入仓
  Reserved     = 多渠道预留 + 订单未发
```

> 🚨 触发专家团：当 **Q × 单位采购成本 ≥ 月毛利 × 60%**（即单笔补货 ≥60 天销量）→ 必须 3 人（库存+算账+跨境）交叉评审。

## 三、断货应急预案（DOS < 20 天 或 实际已断货）

按严重度分 3 档：
### 档 1：DOS=15-20，在途 ≤14 天到仓
→ **保排名动作**：
1. PPC 预算砍 30-50%（别把流量引进来没库存转化）
2. Coupon 降或取消，稳住价格锚点
3. 如有自发货跟卖链接 → 开自发货高价跟卖保 Listing 活性

### 档 2：DOS=7-14，在途 15-30 天
→ **紧急补货（空运/快递）**：
1. 紧急补 15-30 天量走空运（比海运贵但总比掉 BSR 便宜）
2. 加售价 5-10% 节流 + PPC 砍 50%，尽量拖到新货到
3. （如果工厂能出散货）先发 1/3 空运稳住，剩下 2/3 海运降本

### 档 3：DOS<7 或 已断货
→ **救 Listing 动作**：
1. 缺货期间 FBA 改为"预售（可售但是 7 天后发）"或停售自发货
2. 所有 SB/SD 品牌广告不关（保住品牌曝光），SP 精准转化关
3. 新货到后：Coupon 20-30% + Vine 5 个 + PPC 提 Bid 20% → 抢回 BSR
4. 如果断货 ≥ 21 天 → 基本视为新品重做，不要指望还能回到原来 BSR 的 50% 以上

## 四、冗余 / 滞销处理（DOS > 120 天）
> 90 天卖不掉的库存基本就烂仓了，不要指望"旺季会卖" —— 越等越贬值，FBA 长期仓储费能把货值吃光。

按顺序：
1. **Coupon / LD / 7DD 站内清**：给 30% Coupon + 报一次 Deal；成本价能卖掉就是胜利
2. **捆绑 / 买赠**：和主销款打包"买 A 赠滞销 B"，清仓还提 AOV
3. **站外 Deal / 红人**：站外 FB 群组 / Reddit / TikTok 红人发折扣码
4. **Outlet / 清仓平台**：亚马逊 Outlet / 本地清仓平台（回收 20-40% 成本）
5. **销毁 / 捐赠**：连运费都抵不上时，直接销毁 —— 否则仓储费 > 货值

## 五、季节性 / 大促备货日历
- 黑五/网一：提前 **90 天** 下单（7月-8月），FBA 入仓截止 **10/15**
- Prime Day：提前 **75 天** 下单，FBA 入仓截止活动前 **30 天**
- 圣诞 / 年终：提前 90 天；入仓截止 **11/15**
- 国内 618 / 双 11：提前 60 天；入仓截止 5/20 / 10/20
