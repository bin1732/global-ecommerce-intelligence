> 覆盖全球电商平台与品类的全链路智能工具。10 大核心模块 + 6 位专家团 + 10 份 SOP + 反幻觉机制，一站式搞定跨境电商从选品到库存的全流程。

## ✨ 特性

- 🏪 **10 大核心模块** — 选品、合规、定价、利润、跨境、评价、竞品、Listing、PPC、库存
- 🌐 **全球平台覆盖** — 亚马逊 / 速卖通 / Shopee / TikTok Shop / eBay 等主流平台
- 💰 **精准利润计算** — 成本、定价、费率、汇率全链路测算
- 📊 **量化评分体系** — 多维度加权评分，辅助选品决策
- 👥 **6 位专家团** — 老选 / 合规 / 算账 / 跨境 / 评价 / 监价，合规一票否决
- 🔄 **SOP 时效巡检** — 10 份 SOP 定期校验时效性
- 🛡️ **反幻觉机制** — 所有数据标注来源+日期+置信度，估算明示为估算
- 🌏 **多语言自动适配** — 60 种语言映射，自动匹配用户输入语言

## 🧩 核心模块

| 模块 | 功能 |
|------|------|
| 🔍 智能选品 | 多维度量化选品，爆款潜力评估 |
| 📋 平台合规 | 各平台政策核查，合规风险预警 |
| 💲 定价分析 | 成本结构拆解，最优定价推荐 |
| 📈 利润测算 | 全链路利润核算，盈亏平衡点分析 |
| 🌍 跨境出海 | 跨境物流、关税、本地化指导 |
| 💬 评价分析 | 竞品评价情感分析，痛点挖掘 |
| 👁️ 竞品监控 | 竞品价格、销量、策略追踪 |
| ✏️ Listing优化 | 标题、五点、A+ 内容优化 |
| 📢 PPC广告 | 广告结构、关键词、竞价策略 |
| 📦 库存管理 | 库存周转、补货计划、滞销处理 |
