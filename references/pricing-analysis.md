## 定价策略

| 策略 | 适用场景 | 说明 |
|------|----------|------|
| 成本加成法 | 通用 | 成本×(1+期望利润率) |
| 竞品跟随法 | 成熟市场 | 参考头部竞品定价 |
| 价值定价法 | 差异化产品 | 按用户感知价值定价 |
| 渗透定价法 | 新入市场 | 低价进入→提价 |
| 撇脂定价法 | 创新产品 | 高价→逐步降价 |

## 竞品价格分析维度

| 维度 | 说明 |
|------|------|
| 价格分布 | 最低价、最高价、平均价、中位数 |
| 价格区间 | 按价格分段统计产品数量 |
| 价格趋势 | 价格变动历史和时间线 |
| 促销频率 | 竞品降价/优惠券发放频率 |
| 价格弹性 | 价格变动对销量的影响 |

## 利润计算模型

```
净利润 = 售价 - 产品成本 - 平台佣金 - 物流费用 - 营销费用 - 关税 - 退货损耗
```

| 参数 | 说明 |
|------|------|
| 产品成本 | 采购价/生产成本 |
| 平台佣金 | 按平台比例(如Amazon 15%) |
| 物流费用 | 头程+尾程物流+仓储 |
| 营销费用 | CPC广告/站外推广 |
| 关税 | 目标国进口关税 |
| 退货损耗 | 退货率×平均退货成本 |
