> ⚠️ 合规专家拥有**一票否决权**（见 references/engine/AGENTS.md + references/engine/expert-panel.md）。
> 合规红灯未过 → **禁止上架 / 禁止发布 / 禁止上线任何广告文案**。
>
> 【诚实声明】本 SOP 列出的违禁词和认证要求为经验性总结，不构成法律意见；
> 最终上架前请以平台后台「禁售商品 / 广告政策」最新版本 + 目标国监管机构（FDA/CE/CPSC 等）官方文件为准，属于 **[T0-实时][低]** 级别时效性数据。

## 一、合规审核触发 5 类场景（全命中）

1. **新品首次上架前**（最常见，100% 要过）
2. **Listing 主属性修改**：标题 / 五点 / 描述 / 主图 / A+ 任何一项修改 ≥30%
3. **目标国家 / 平台变更**（比如之前只做北美，现在加欧洲站）
4. **大促文案上线前**：Coupon / Deal / 站外 Post / 广告图文案
5. **平台政策更新通知**（收到官方"禁售类目调整"邮件时）

## 二、4 关审核（每关 100% 过才算通过）

### 🚦 关 1：平台违禁词 & 绝对化用语检查
调用 `knowledge-filter --entry compliance` 加载：
- references/platform-rules.md 「违禁词/绝对化词清单」
- references/cross-border-guide.md 「目标国特殊合规」

手动或关键词扫描检查：
- 绝对化：最/第一/最佳/100%/国家级/永久/无副作用（医疗类更严）
- 医疗宣称：治愈/治疗/消炎/抗菌/减肥/增高/美白（美妆食品类）
- 名人/商标：迪士尼/漫威/耐克/专利词 未授权 = 侵权
- 宗教 / 种族 / 性别歧视词 → 直接封店级

### 🚦 关 2：类目准入 + 强制认证检查
| 目标平台 | 常见高风险类目 | 通常需要的认证 |
|---------|---------------|---------------|
| 亚马逊北美 | 婴童用品 / 家电 / 灯具 | CPC / FCC / UL 报告 |
| 亚马逊欧洲 | 所有电子 / 个人防护 | CE / RoHS / WEEE / REACH |
| 亚马逊日本 | 电子 / 无线 | PSE / TELEC / VCCI |
| 淘宝国内 | 食品 / 美妆 / 医疗器械 | 食品经营许可 / 化妆品备案 / 二类医械证 |
| 所有跨境 | 带电 / 带磁 / 液体 / 粉末 | MSDS / 运输鉴定报告 |

- 红线：认证缺 = 先不要发大货，先办认证（多数 2-6 周能办下来）
- 合规专家此时**一票否决**：认证没办的一律打回

### 🚦 关 3：目标国税务 & 进口合规
- 欧盟：VAT 号 + EORI 号（否则卡清关）
- 美国：销售税许可证（州级差异大）
- 英国：VAT 号
- 中东/东南亚：各国 VAT/消费税
- 红线：税务缺号就发货 = 扣货 + 罚款 + 封账号

加载 `knowledge-filter --entry cross-border` → references/us-sales-tax.md

### 🚦 关 4：知识产权（商标 / 专利 / 版权）三重排查
1. 商标：目标国 + 目标平台的官方商标数据库查同名
2. 外观专利：Amazon/Shopee 首页同款前 3 页 + 阿里外观库
3. 发明专利：高危类目（如小家电/玩具/美妆工具）必须查
- 红线：风险≥中 → 不要硬上；找专利律师出不侵权意见书（FTO）再上

## 三、结论输出模板

必须分 3 档：

```
【合规结论】🟢 PASS / 🟡 有条件 PASS / 🔴 FAIL

关1 违禁词：✅通过 / ❌N 处命中（列出命中词+位置）
关2 类目认证：✅已齐 / ❌缺 X / Y / Z 认证（预计 Z 周办完）
关3 税务进口：✅已齐 / ❌缺 VAT/EORI
关4 知识产权：✅未发现 / ⚠️有外观风险（附证据）/ ❌已确认侵权

【一票否决】🔴 FAIL 时 → 合规专家已否决上架，原因：___
【有条件 PASS 行动清单】N 项：
  1. (办认证) — 预计 XX 天
  2. (改词) — 列出改前/改后对照
【下次复核】YYYY-MM-DD
```
