## 价格战应对策略

### 被动应对（竞品先降价）

| 竞品降幅 | 推荐策略 | 说明 |
|----------|----------|------|
| <5% | 不跟降 | 保持价格，强化差异化卖点 |
| 5-10% | 观察期 | 观察3-5天，确认是长期策略还是短期促销 |
| 10-20% | 跟降+加值 | 匹配价格同时增加赠品/服务提升感知价值 |
| >20% | 差异化坚守 | 不跟降，强化品质/服务差异，避免陷入价格战 |

### 主动定价策略

| 策略 | 适用场景 | 风险 |
|------|----------|------|
| 渗透定价 | 新品上架，快速获取市场份额 | 利润薄，后期涨价难 |
| 撇脂定价 | 独特产品，差异化明显 | 销量可能受限 |
| 竞品锚定 | 竞品有明确价格带 | 被竞品牵着走 |
| 价值定价 | 品牌溢价能力强 | 需要品牌支撑 |
| 动态定价 | 数据驱动，实时调价 | 需要监控工具支持 |

## 价格弹性测试框架

### 测试步骤

```
Step 1: 基准期(7天)
  → 记录当前价格下的日均销量和转化率
  
Step 2: 提价测试(7天)
  → 价格上调5-10%，观察销量变化
  → 计算价格弹性系数（中点法，与 price-elasticity.mjs 一致）: E = (ΔQ/Q_avg) / (ΔP/P_avg)
  
Step 3: 降价测试(7天)
  → 价格下调5-10%，观察销量变化
  → 计算降价弹性系数
  
Step 4: 分析结论
  → |E| > 1: 弹性大，降价可提升总收入
  → |E| < 1: 弹性小，提价可提升总收入
  → |E| = 1: 单位弹性，收入不变
```

### 弹性系数参考

| 品类 | 价格弹性 | 定价建议 |
|------|----------|----------|
| 电子产品 | 高弹性(1.5-2.5) | 薄利多销，价格敏感 |
| 服装鞋帽 | 中弹性(1.0-1.5) | 适度促销，差异化定价 |
| 家居用品 | 中弹性(0.8-1.2) | 价值定价可行 |
| 美妆护肤 | 低弹性(0.5-1.0) | 品牌溢价空间大 |
| 食品饮料 | 高弹性(1.5-3.0) | 促销驱动销量 |
| 奢侈品 | 极低弹性(0.1-0.5) | 提价反而可能增加销量 |

```
  3. 3天后评估竞品A是否持续低价
```
