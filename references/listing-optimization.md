## 二、标题优化公式

### Amazon 标题公式

```
[品牌名] + [核心关键词] + [核心特性1] + [核心特性2] + [适用场景] + [关键规格]
```

**规则**：
- 长度：120-200字符(移动端显示前70字符)
- 关键词前置：核心词放前50字符
- 禁止：促销词("Best seller""Free shipping")、全大写、特殊符号堆砌
- 数量单位明确：标明 pack of 2 / 500ml 等

**示例（差→好）**：
- ❌ `Wireless Earbuds Best Quality Sound`
- ✅ `SoundCore Mini Wireless Earbuds Bluetooth 5.3, 24h Playtime, Noise Cancelling, IPX7 Waterproof for Running`

### Shopee 标题公式

```
[核心关键词] + [特性] + [适用] + [促销标签可选]
```
- 长度：120字符内
- 关键词前置(Shopee搜索权重标题前段更高)

### 淘宝标题公式

```
[品牌/修饰词] + [核心词] + [属性词] + [长尾词] + [场景词]
```
- 30个汉字(60字符)
- 空格分词,不用特殊符号
- 不要堆砌重复词

## 三、五点描述(Bullet Points)模板

Amazon 五点结构（每点 200-250 字符）：

```
1. 【核心卖点1】+ 具体数据 + 用户获益
2. 【核心卖点2】+ 具体数据 + 用户获益
3. 【材质/规格】+ 具体参数 + 适用场景
4. 【使用场景】+ 多场景描述 + 适配人群
5. 【保障/服务】+ 售后承诺 + 品牌背书
```

**示例**：
```
1. 【24小时超长续航】单次充电8小时+充电盒16小时,通勤一周不充电
2. 【主动降噪ANC】降噪深度-35dB,地铁/飞机/咖啡厅安静如初
3. 【蓝牙5.3芯片】连接稳定0延迟,游戏/视频音画同步
4. 【IPX7防水】运动出汗/小雨无忧,跑步健身首选
5. 【品牌保障】SoundCore 18个月质保,7×24客服,30天无理由
```

## 四、关键词研究框架

### 关键词分层

| 层级 | 类型 | 搜索量 | 竞争度 | 优先级 |
|------|------|:------:|:------:|:------:|
| L1 | 核心大词 | 高 | 高 | 标题必埋 |
| L2 | 长尾词 | 中 | 中 | 五点+后台 |
| L3 | 场景词 | 低 | 低 | A+详情 |
| L4 | 竞品词 | 中 | 高 | 广告投放 |

### 关键词挖掘渠道

- Amazon 搜索框联想词
- 竞品 Listing 标题/五点词频
- Brand Analytics 搜索词报告(品牌注册卖家)
- Helium10 / Jungle Scout 工具
- Google Trends 验证趋势

### 关键词埋点检查清单

- [ ] 标题含 1 个 L1 核心词
- [ ] 标题含 2-3 个 L2 长尾词
- [ ] 五点每点含 1 个 L2 词
- [ ] 后台 search terms 填满 L3 词(不重复标题词)
- [ ] A+ 文案含场景词

## 五、主图规范(各平台)

| 平台 | 尺寸 | 背景 | 文字 | 主图要求 |
|------|------|------|------|---------|
| Amazon | ≥1000×1000px(可缩放≥1600) | 纯白(#FFFFFF) | ❌禁止 | 单品占85%,无水印/Logo |
| Shopee | ≥1024×1024px | 纯白或浅色 | 限少量 | 单品为主,可加角标 |
| 淘宝 | ≥800×800px(主图≥1000) | 灵活 | 允许 | 第一张白底,后续可场景 |
| TikTok Shop | ≥800×800px | 灵活 | 允许 | 竖屏9:16更佳 |

### 副图标配(6张)

1. 尺寸对比图(参照物)
2. 功能细节图
3. 使用场景图
4. 包装内容图
5. 对比优势图
6. 资质/认证图

## 六、A+ 内容(EBC)框架

### 模块结构

```
1. 品牌故事模块 — 品牌理念+差异化
2. 核心卖点模块 — 3-4个卖点图文
3. 对比模块 — 与普通产品对比(不指名竞品)
4. 使用场景模块 — 多场景展示
5. 规格表模块 — 详细参数
6. FAQ模块 — 常见问题预解答
```

### A+ 优化原则

- 图文比 7:3(图为主)
- 每模块一个核心信息
- 文案短句+数字+获益
- 避免纯文字墙
