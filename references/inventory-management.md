## 一、库存模式对比

| 模式 | 时效 | 成本 | 适合 | 风险 |
|------|:----:|:----:|------|------|
| FBA | 1-3天 | 高 | 热销品/Best Seller | 长期仓储费/库存限制 |
| 第三方海外仓 | 2-5天 | 中 | 中等销量/大件 | 管理复杂 |
| 国内直发 | 10-20天 | 低 | 测试新品/长尾 | 时效慢/转化低 |

## 二、补货量计算公式

### 基础补货公式

```
补货量 = (日均销量 × 备货周期天数) - 当前库存 + 安全库存

备货周期 = 采购周期 + 生产周期 + 头程物流 + FBA上架
安全库存 = 日均销量 × 安全天数(建议7-14天)
```

**示例**：
- 日均销量 30 单
- 备货周期 35 天(采购7+生产15+物流10+FBA上架3)
- 安全天数 10 天
- 当前库存 500 单

```
补货量 = (30 × 35) - 500 + (30 × 10) = 1050 - 500 + 300 = 850 单
```

### 安全库存设置

| 销量稳定性 | 安全天数 | 说明 |
|-----------|:--------:|------|
| 极稳定(老品) | 7天 | 销量可预测 |
| 较稳定 | 10天 | 季节性弱 |
| 波动大 | 14天 | 节日/促销品 |
| 极不稳定 | 21天 | 新品爬坡期 |

## 三、断货应对

### 断货成本

> 行业经验估算 [置信度:中]
- BSR排名下滑：断货3天，BSR可能跌50%+
- 自然流量下降：断货7天，自然位可能掉出首页
- 恢复周期：断货1周，恢复需2-4周广告+测评
- FBA断货额外影响：Buy Box丢失

### 断货前预警

| 库存可售天数 | 预警等级 | 动作 |
|:----------:|:--------:|------|
| >45天 | 🟢正常 | 正常补货 |
| 30-45天 | 🟡关注 | 启动补货流程 |
| 15-30天 | 🟠紧急 | 加急补货+暂缓广告 |
| <15天 | 🔴危险 | 紧急空运+全面降广告 |
| <7天 | ⚫临界 | 提价5-10%降速+空运 |

### 断货中应急策略

```
1. 提价 5-15% → 降低销量速度(但注意不要超过平台涨价限制)
2. 降广告预算 50%+ → 减少流量消耗库存
3. 紧急空运补货 → 哪怕亏运费也要保位
4. 创建removal order → 把冗余SKU库存调到断货SKU(如适用)
5. 跟卖自己(自发货) → FBA断货时自发货兜底(注意合规)
```

## 四、冗余库存处理

### 冗余判定

| 库存可售天数 | 状态 | 处理 |
|:----------:|:----:|------|
| 90-180天 | 🟡偏多 | 促销/降价 |
| 180-365天 | 🟠冗余 | coupon/deal/清仓 |
| >365天 | 🔴长期 | 移除/销毁(避免长期仓储费) |

### 清仓策略(按优先级)

```
1. 站内促销
   → Coupon(5-20% off) → 最低成本清仓
   → Lightning Deal → 流量大但需付费
   → Prime Exclusive Discount → 会员专享折扣

2. 站外清仓
   → Facebook Marketplace / eBay 残值出
   → 批发给清仓商(5-3折)

3. bundle 搭售
   → 滞销品+热销品捆绑,热销品提价补差

4. 移除/销毁
   → Removal Order 调回国内(残值>运费时)
   → Dispose 销毁(残值<运费时,避免长期仓储费)
```

### FBA 长期仓储费

> 以Amazon美国站为例,具体费率以官方为准 [置信度:中]

| 库龄 | 费率(每立方英尺) | 说明 |
|------|:---------------:|------|
| 271-365天 | $6.45 | 中期附加 |
| >365天 | $12.10 | 长期附加(每半年清算) |

**避免长期仓储费的关键**：库龄超180天就开始清仓,别拖到365天。

## 六、季节性库存规划

### 季节品备货时间线

```
T-120天：预测销量+下首批订单
T-90天：生产中+订舱
T-60天：头程发运
T-30天：FBA上架+广告预热
T-0：旺季开售
T+30天：旺季复盘+清尾货决策
```

### 旺季备货量

- 黑五/网一：备货量为日常3-5倍
- Prime Day：备货量为日常2-3倍
- 双11/618：备货量为日常3-5倍
- 春节(国内)：提前30天备货(工厂停产)

## 七、库存与现金流的平衡

```
库存占用资金 = 平均库存 × 单件成本
健康的库存周转 → 现金流良性

现金周转周期 = 库存周转天数 + 应收天数 - 应付天数
  → 越短越好(负数最佳,说明供应商垫资)
```

**新手建议**：
- 首批备货不超过总预算40%(留60%做广告/测款)
- 单SKU备货不超过2个月销量
- 优先测小批量(50-100件),跑出数据再大批备货
